ЭЖЛ — ЭЛЕКТРОННЫЕ ЖУРНАЛЫ ЛАБОРАТОРИИ
Руководство для лаборанта
═════════════════════════════════════

УСТАНОВКА (один раз)
────────────────────
1. Распакуйте архив EJL-win-x86.zip в любую папку,
   например на Рабочий стол (появится файл EJL.exe).
2. Ничего устанавливать не нужно — программа самодостаточна.

ПЕРВЫЙ ЗАПУСК
─────────────
1. Запустите EJL.exe двойным кликом.
2. Если Windows покажет синюю плашку «Система Windows защитила ваш компьютер»:
   нажмите «Подробнее» → «Выполнить в любом случае».
   (Появляется один раз для неподписанных программ — это нормально.)
3. Откроется окно программы. Подождите несколько секунд.

ВХОД В СИСТЕМУ
──────────────
Демо-пользователи (пароль у всех: demo123):

  admin  — администратор (настройка журналов и пользователей)
  head   — заведующий лабораторией
  qm     — менеджер по качеству (проверка журналов)
  eng1   — инженер (право списания прекурсоров)
  lab1   — лаборант
  lab2   — лаборант

РАБОТА
──────
• Журналы — внесение записей; результат испытаний считается автоматически.
• Исправить запись можно только с указанием причины — прежнее значение
  сохраняется в истории (зачёркнуто при печати).
• Материалы — поступление и списание реактивов; прекурсоры списывает
  только сотрудник с отдельным правом.
• 💾 — создать резервную копию базы данных (файл появится в папке backup).
• 🔔 — напоминания: сроки годности, ежедневные записи, проверки журналов.

ГДЕ ХРАНЯТСЯ ДАННЫЕ
───────────────────
Все данные — на этом компьютере, в папке
  C:\Users\<имя>\AppData\Local\EJL\ejl.db

РЕЗЕРВНЫЕ КОПИИ
────────────────
Нажмите 💾 в верхней панели — копия сохранится в
  C:\Users\<имя>\AppData\Local\EJL\backup\

Копию можно перенести на флешку или диск. Для восстановления — заменить
файл ejl.db копией (при закрытой программе).

ЗАВЕРШЕНИЕ РАБОТЫ
─────────────────
Закройте окно программы — через минуту она завершится сама,
корректно сохранив все данные.

ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ
────────────────────────
Загляните в файл C:\Users\<имя>\AppData\Local\EJL\ejl.log —
его можно приложить к сообщению разработчику.
